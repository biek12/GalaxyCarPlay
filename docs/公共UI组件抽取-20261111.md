# 公共 UI 组件抽取（独立任务）

2026-11-11，用户纠正：公共 UI 指真实组件，不是启动设置、Wi-Fi或权限等功能 SDK。用户已通过审计并授权编码。当前核心控件已迁入`:auto-ui`，具体实现和验证入口见`galaxy/ui/README.md`。

目标模块 `galaxy/ui`（`:auto-ui`），与 CarPlay 协议、AutoService Binder、车辆 SDK 和业务设置无依赖。先迁移 mobile 实际使用的 galaxy/common UI 实现，CarPlay 原入口委托公共组件，验证无行为变化，再供其他 App 使用；不能重新写一套相似控件而让原实现继续独立维护。

| 公共组件 | 当前源码依据（galaxy/common/.../com/shilapi/xcertplay） | 抽取契约与验证 |
| --- | --- | --- |
| 文本与文字角色 | L7Typography.kt、L7Ui.kt | 标题／正文／值／说明／反馈，sp、行高、日夜、字体放大 |
| 列表与设置行／分组 | L7SettingRow.kt、L7SettingsCard.kt、L7SettingsSection.kt | 标题、说明、当前值、反馈、图标及操作槽；长值自动另行；保留行点击与无障碍 |
| 按钮／图标按钮 | L7ActionButton.kt、L7Components.kt、L7Icons.kt | 主／次／图标、禁用／按压／焦点，不将文案推断图标规则带入公共组件 |
| 弹窗 | L7Dialogs.kt、L7ModalDialog.kt | 消息、确认、列表选择、嵌入内容、取消／关闭；业务草稿提示由调用方决定 |
| 选择切换 | L7Components.choice/select、现有Tab控件 | 分段／Tab与单选：当前值、待选值、取消不提交、确认只发一次 |
| 开关 | L7SwitchStyle.kt、L7Components.switchRow | 原Flyme轨道／滑块、64dp命中区域；外部回填不触发业务回调；整行点击与无障碍单一入口 |
| 输入 | L7Ui.input | 焦点、提示、错误、禁用、长内容；不耦合业务校验 |
| 头部与导航 | L7Header、既有导航容器 | 返回、标题、动作槽；不内置App功能菜单 |

公共组件只接收状态和事件。连接、写入、权限、Wi-Fi跳转等放各业务模块／功能SDK。新的 `NativeWifiSettings` 已移至 AutoService `settings` 包，不属于 auto-ui。

本轮已迁出：文字角色／度量、主题样式、按钮、设置行／长值排版、列表卡／分组、完整模态弹窗／焦点恢复、选择确认／分段、开关／外部回填、输入框。mobile与旧L7资源名保留alias／委托；CarPlay业务文案、图标策略与密度从宿主注入。AutoCluster新页面和部分既有主题界面复用公共组件。通用头部／导航容器及其他App全部历史控件的迁移尚未完成，不将核心组件迁出等同于所有历史页面都已改造。

验收：组件样例单独展示各状态，不放到AutoCluster用户页面；同状态对照CarPlay原控件，覆盖日夜、长中文、字体放大、禁用、取消、单次点击回调、外部状态回填。布局与业务解耦后，CarPlay和其他App才共同消费，避免继续出现多份实现。
