# 私有部署配置

Git 的当前文件和历史不得包含自有服务器真实域名、IP、密钥或部署身份材料。公共依赖、上游项目链接和协议示例不受此限制。示例地址使用 `example.invalid` 或文档保留网段。

Android 构建从忽略目录 `.private/server.properties` 读取 `bridge.origin`，也可由环境变量 `GALAXY_ORIGIN` 覆盖。未配置时生成示例地址，仅供公开源码编译，不能连接个人服务。既有 AutoService 已保存的 origin 优先保留。私有构建的 APK 会包含实际连接地址，不能作为已脱敏源码分发。

部署前在本机载入私有环境文件，例如 `source .private/server.env`。脚本使用 `GALAXY_SERVER_SSH`、`GALAXY_SERVER_SSH_KEY`、`GALAXY_ORIGIN` 和远端代理配置路径 `GALAXY_PROXY_CONFIG`；TURN 部署还需要 `GALAXY_TURN_PUBLIC_IP`、`GALAXY_TURN_RELAY_IP`、`GALAXY_TURN_REALM`。

服务器 systemd 单元从 `/etc/galaxyplay-bridge/server.env` 读取 `GALAXY_WEB_ORIGIN` 与 `GALAXY_TURN_URLS`。该文件仅保存在服务器；升级脚本可从已有单元迁移两项配置，首次部署须先私有准备此文件。密钥仍从服务器私有文件读取。

本次仅修改源码与 Git 历史，没有部署服务器或更新车辆。
