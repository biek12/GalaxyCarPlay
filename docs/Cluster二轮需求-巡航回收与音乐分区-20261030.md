## 当前组件结构

通用注册表由17扩至24类、每类3个预设共72个；新增独立油/电续航条、回收、音乐背景、信息分页、能耗趋势、状态图标行。`builtin-reference`是普通可导出的组件树，音乐容器内部仍为背景/曲目/歌词/进度独立子组件。菜单四页的子树、默认页/草稿预览页、页序和切换动画都保存在主题属性中；不存在按主题名称切换专用Renderer的硬编码。

地图支持圆角开关/半径、虚化开关/半径、边缘/整体、边缘宽度及渐隐；实际视频使用API30可运行的GLES对称九点采样，不依赖API31 RenderEffect。主题只提供透明孔与边缘渐隐；正式视频始终来自CarPlay，不把预览路网称作导航。音乐背景的区域即独立背景组件矩形，可移动缩放；纯色/渐变/封面/地图毛玻璃可选，背景透明度/内缩/圆角/模糊独立可调。封面在IO线程生成最多256px的缓存柔焦版本，换图/参数变化才重算，不逐帧CPU模糊。

原车续航位置/样式没有采集完成：还原模板中的两个独立条节点留在图层中但默认不绘制，连接后据原车标定启用；胎压页清楚标注待原厂视觉对照，没有拿自绘轮廓冒充原厂。已有独立自绘胎压组件保留在组件库。中部来电浮层没有加入；此模板时钟明确不显示日期。
