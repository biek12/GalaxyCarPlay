## 公开素材检索与替换

用户要求继续检索，并建议沿自定义仪表巡航样式及小米/理想的行车记录仪录屏学习。实际检索与检查：

- 工程 `galaxy/cluster/.../GaugePainter.kt` 的 `cruiseIcon` 为圆弧+指针+圆心；`IndicatorPainter.kt` 同类。本轮据此选现成原始矢量，不把旧Canvas绘图复制成新手绘图标。
- 理想水印说明实拍：[新出行原帖](https://www.xchuxing.com/ins/786913)。已打开实际图，能直接辨认加速踏板为脚踩踏板，制动踏板为脚+圆环。用于形态对照，没有把整张他人照片打入APK。
- 小米行车信息叠加公开画面：[2024-08-12介绍](https://finance.sina.com.cn/tech/roll/2024-08-12/doc-incikerc4343926.shtml)。已打开该公开配图，确认画面下方状态行；图片分辨率不足以取得独立高清图标，不冒充原始素材来源。
- 刹车：Noun Project / Mateusz Skrzyniecki / Press Brake Pedal #1353193，CC BY 3.0，原始512px透明PNG不改写。
- 加速：Noun Project / LAFS / Pedal #1368276，CC BY 3.0，原始512px透明PNG不改写。是脚踩踏板通用图形，不把“离合”命名素材改名成加速。
- 巡航：Volvo Cars shared icons v5 / speedo-set，圆弧+指针，删除原MDI图标中不合参考的外侧大箭头。
- 方向盘、后雾灯、P：同目录 steering-wheel / foglight-rear / parking-brake 原始矢量路径。A沿用auto-brake。状态5仍不绑定猜测含义，P按gear=P。

普通图标保持Lucide；本轮现成素材的作者、URL、源摘要与许可记录位于 `assets/licenses/vehicle-assets.json`，About保留踏板归属说明。仅Android显示时缩放/染色，不自行描摹。**这是采用品牌同类形态的现成素材替换，不宣称与IMG_0660逐像素相同，也不代表全部App视觉验收通过。**
