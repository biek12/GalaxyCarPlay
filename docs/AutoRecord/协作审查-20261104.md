基于首批4个Kotlin候选的源码预审，**不接受集成**。这不是实车问题，也不是测试通过结论。

4. **P2 身份与时钟**：`ChannelWriteResult`没有事务身份，旧段收尾结果可被新段同方向接受；补不可混用的段/事务标识，提交时校验，合法重复与冲突重复分开。`durationMillis = max(lastPtsUs)/1000`把绝对PTS当时长；明确PTS是段相对还是会话单调域，依锚点/首末PTS计算，不能把系统uptime写为录像时长。多个样本首末PTS相等也应拒绝。补旧事务结果、非零首PTS与相等PTS测试。
