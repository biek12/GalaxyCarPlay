## 4. 仪表：完整导航地图与音乐可视信息的端到端输出

### 最新需求口径与研究完成标准

- 音乐是封面、进度、标题、歌词等可视信息，不是PCM/声音。本文音频路由与EAS注册章节不能作为仪表音乐展示已完成的依据。
- 导航是完整地图，含车道级导航、到达时间、距离、限速、转向等信息；下面的TBT服务映射仅是配套协议，不替代地图画面。
- 下一步沿参考实现逐项核清：内容取得入口 → 解码/字段解析 → 状态同步 → 地图/音乐绘制与组合 → 图像或缓冲区提交 → HAB→QNX接收与显示。需列出每一步实际类、方法及数据形态。
- 当前已见111/Surface接口与HAB路线记录，尚未证明参考实现如何把全部目标内容组合并提交；不得把出口定位写成端到端研究完成，也不得假定111流本身含所有音乐/地图字段。
