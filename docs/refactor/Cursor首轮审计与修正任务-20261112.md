1. 记录当前脚本/归档字节与 Git 状态。固定自有 Shell、Kotlin/KTS、XML、Python 等文本后续 LF；`archive/** -text` 保留原字节。只恢复已知 53 个旧归档项的精确 Git blob，不做校验前 CRLF→LF 宽容处理，不修改 manifest。运行脚本依赖的本批自有文本按 LF 物化，不能用 `git add --renormalize .` 整仓改写。
2. 以 `F:\GalaxyPlay\galaxycarplay\.work` 为显式共享缓存根；每个 worktree 编译输出与报告只写自身 `.work`/build。校验 ktlint 1.4.1 SHA256 `abff61ead7dabdf1264ae7dce61cb5325e602896f33f3ee2fbc359238adeac70`。AAPT2 使用本机已核验 Windows 二进制，不能运行 ZIP 的 Mac 工具。Gradle 已能配置，不为此升级 wrapper/AGP/业务库或机械重装 JDK。
3. 从 ZIP 选择性迁移 Java/Maven 可移植包；需补公开依赖时按锁定版本准备，再实际 offline 解析。检查需要的 Robolectric JAR 是有效 ZIP 且必要 class 存在，记录来源/摘要；不用不足 200 字节的占位包，不改测试 SDK 来绕开缺依赖。
4. 原 `archive_gate` 继续校验原始字节、manifest、固定 Git blob 三方相等。`classes_gate` 使用 `as_posix()` 等平台无关相对路径。`closure_gate` 不再把说明注释判为配置，但真实旧 bridge 配置/类/Manifest 仍拒绝。保留 op4/op6 拒绝及 op11/op12/共享 health 的要求。
5. Windows runner 接受 `-CacheRoot`、`-ReportDir`、`-KtlintJar`、`-Aapt2Path`，使用参数数组传递 native 命令，尤其 `-Pkotlin.incremental=false` 等含点参数不能被 PowerShell 拆成额外任务。原 Shell 入口仍可运行。父子入口缓存/报告一致，原用例精确匹配、零失败/错误/跳过不变。
