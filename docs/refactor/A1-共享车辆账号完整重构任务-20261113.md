## 4. 完整状态、时间和错误规则

### 单一状态与呈现

1. 车辆basicInfo/owner等JSON字段继续按原optString/optBoolean/optLong默认值解析；不补假车辆/手机号，不将缺字段推断为已绑定。
2. bound=true：显示已绑定卡/owner/解绑入口，隐藏申请码卡；保持绿色长期有效；调试授权到期不影响bound显示。未bound显示添加卡。
3. 临时码只有code非blank且expiresAt>nowMillis才显示二维码、可选中文本code及有效至说明。旧标题按仍有有效期决定扫码添加/添加到账号；申请按钮仍按有效期切重新申请/申请。
4. bindings按服务器顺序，expiresAt<=now的行全部过滤；未过期的待确认请求可以与二维码同时显示。列表有多个账号时各自回调绑定准确bindingId，不因刷新/删除改变目标。
5. hints优先级仍是reply.error→最新JSON.error→enabled对应两句正常说明。无效JSON或reply没有json不清空最后一份有效车辆数据；错误仍反馈，不因解析失败假造成功。
6. busy时所有会提交动作的按钮禁用并保留Presenter防重入；返回继续可用。结束后按真实connected/busy恢复，不让纯render触发一次请求。

### 此次同时关闭两个已有页面缺陷

- **断线后busy卡死**：AutoClient会丢弃旧连接代次结果，而旧Activity的busy只在result里清零。Presenter收到实际连接失败/丢失（ipc:/connect:/bind:、service_disconnected、binding_rejected/binding_died/service_unavailable）后使当前请求票据失效、释放busy、显示未连接；onReady的新连接要立即能请求state。旧结果之后回来不能清掉新请求busy或覆盖状态。不能去修改AutoClient实现或新增页面重连计时器。
- **未变化JSON的待确认行到期**：旧signature只含code是否到期，待确认绑定单独到期会残留。每个2秒tick即使busy/离线也从同一最新JSON重新计算时间可见性；真正发state仍要求connected&&!busy。渲染签名必须包含有效码/有效bindings身份或等价State比较；不显示每秒倒计时，不为刷新时间额外请求服务器。

这些是既有关闭/到期意图的页面缺陷修正，不改变绑定期限、服务器权威、授权合同或录制数据。未提供的服务端字段不猜补。

## 5. 生命周期、线程与二维码所有权

### 创建到退出

- onCreate先inflate/装配并绑定点击，再创建唯一Presenter/ClientPort并connect，保持原观察者角色。onReady立即state。
- onStart只有一个ticker，立即运行一拍并每2000ms续投；重复start不叠加。onStop移除ticker，不关闭车辆在线服务，不自动解绑/disable；恢复后同一连接再轮询。
- request先检查closed/connected/busy，成功发出只占一个busy；非state显示处理中。回调必须在main，同请求票据才采纳reply、释放busy、解析并绑定。未返回期间不自行宣称成功。
- destroy先标closed并使请求/QR票据失效、移除tick，清ImageView引用/关弹窗；关闭QrRenderer与同一个AutoClient各一次。不在退出后更新View或回调，借用的main Handler不被全局清空。
- JSON和按钮状态只在main维护。现有AutoClient已负责Binder worker，Presenter不另开网络线程，也不在onCreate同步读凭据/磁盘或申请权限。

### QR编码

- 用既有`QRCodeWriter.encode(scanUrl, QR_CODE, 512, 512)`、ARGB_8888黑白像素；不改变链接、扫码参数或静默追加身份。
- Renderer一个页面最多一个专属HandlerThread和一个可合并待处理任务：后来的码覆盖尚未处理的输入，不按2秒tick无限排队。可复用同码结果，不每次render重建512位图。
- encode完成回main时检查closed、页面代次和当前scanUrl/有效期；旧码/到期/已bound结果不挂回ImageView。编码异常以资源提示并保留文字code和重新申请入口，不崩溃、不造假二维码。
- 每个Bitmap只有一个明确owner。未交给UI的失效结果由Renderer回收；交给UI后，先清/替换ImageView引用，再回收旧owned位图。不能回收正在显示的图，close后结果只能回收，不能复活页面。只终止自有QR worker，不清main全队列、不改AutoClient worker。
