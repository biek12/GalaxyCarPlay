# U1 实现记录（公共 XML 组件与 AutoService 页面）

批次：GALAXY-ANDROID-U1-20261111。起点 `cf83158bd735282d418aa8e033bf7d9303b8bff7`；分支 `feat/galaxy-android-u1-20261111`。
逐项迁移表见任务目录 `METHOD_MAP.md`，验证证据见 `VALIDATION.md`，行为差异见 `CHANGES.md`。

## 1. 公共 UI：在既有实现上补 XML/资源

沿用 `Galaxy*` 与 `L7*` 的同一条实现线，只为静态骨架补 XML、为样式补资源；测量、焦点、确认与回填算法原样保留。

| 组件 | 静态骨架 | 保留的原逻辑 |
| --- | --- | --- |
| `GalaxySettingRow` | `galaxy_ui_setting_row.xml`（`<merge>`：icon / 文字区 / accessory） | 80/96dp 行高规则、`textInset`、`setAccessory` 槽位移、`setSwitchChecked` 回填不回调、`onMeasure` 增高 |
| `GalaxySettingTextLayout` | `galaxy_ui_setting_text.xml`（label/value/description/feedback） | inline 短值判定（≤45% 且能同行）、逐行排列、RTL 摆放、`gap`/`valueGap` |
| `GalaxyViews.text/textButton/button/iconButton/group` | `galaxy_ui_{text,button,icon_button,group}.xml` | 角色字号/行距、64dp 命中、禁用不回调、图标 tint |
| `GalaxyViews.attachSwitch` | `galaxy_ui_switch.xml` | 回填不回调、整行点击转发、单一无障碍入口（新增的唯一开关插入实现，`switchRow` 与 AutoService 共用） |
| `GalaxySettingsCard` | `drawable/galaxy_ui_card.xml` | 相邻 `GalaxySettingRow` 分隔线（登记的绘制例外） |
| `GalaxySections` | `galaxy_ui_section.xml` / `galaxy_ui_actions.xml` | header/description/footer 空值显隐、24dp 分组间距 |
| `GalaxyModalDialog` | `galaxy_ui_dialog.xml` + `galaxy_ui_dialog_choice.xml` | 单一滚动 body、footer 槽、`closeRequest` 优先、宽度 88%/720dp、fixedHeight 72%、`styleInputs` |
| `GalaxyDialogPanel` | 同上根节点 | 原 `BoundedPanel` 的 82% 高度上限 |
| `GalaxySelection.segments` | `galaxy_ui_segments.xml` + `galaxy_ui_button.xml` | 只发布选中索引、weight 平分 |

字号/颜色/圆角/触控尺寸进入 `values/{dimens,styles,attrs}.xml`、`color/*.xml`、`drawable/*.xml`；
`GalaxyUi.TextAppearance.*` 与 `GalaxyTypography.Role` 数值一致，前者供 XML，后者供代码创建。

## 2. L7 兼容入口：只委托，不留第二份实现

- `L7Components.iconButton/text`、`L7Typography.text` 改为委托 `GalaxyViews`，宿主只覆盖颜色别名；
- `L7SwitchStyle` 委托 `GalaxySwitchStyle`；`L7ActionButton/L7SettingRow/L7SettingsCard/L7SettingsSection` 保持别名；
- `L7Components.switchRow/select` 去掉全限定名改显式 import；
- CarPlay 的重连提示、草稿文案、图标策略、密度注入仍在 `L7Dialogs/L7Ui/L7Icons`，未下沉到 `auto-ui`。

## 3. AutoService 首页

`ServiceActivity` 只剩 `setContentView(binding.root)`、创建 Presenter 与生命周期委托（`onStart/onResume/onStop/onDestroy`）。

- 布局：`activity_service.xml` + `include_service_{header,overview,wifi_help,features,remote}.xml`；概览三项指标固定顺序、功能开关在 XML 直接声明 `GalaxySettingRow` 并带稳定 ID；
- 状态：`ServiceHomeState.from(resources, automatic, features, snapshot, connected, wifiEnabled, remote, nowMillis)` 只产出文案/色调/可见性/开关确认值；`foundation` JSON 异常保留空对象语义；
- 操作：`ServiceHomeActions` 复用既有设置类，保持"先落盘再发命令"；全部关闭顺序 `RemoteSettings.disable → ServiceFeatures.disableAll → AutoStartup.cancel → STOP`；失败 `ServiceTrace.event` + 资源化 Toast；
- 观察者：`ServiceHomePresenter` 单一 owner，`start` 只建一个连接/ticker，`stop` 移除 ticker 并关闭连接、失效代次；ticker 仅前台 1s 刷新远程文案；
- 会话边界：`ui/ServicePageSession.kt` 提供 `connect/close/executeShell/setVehicleScan/vehiclePage`，`AutoClientPageSession` 只委托一个真实 `AutoClient`（OBSERVER、Shell 超时 10000ms）；`AutoClient` 未修改；
- 命令归属：`settings/ServicePageCommands.kt` 集中 action/extra 与认证文件请求码，`FEATURES_CHANGED` 引用 `ServiceFeatures.ACTION_CHANGED`；
- 删除 `ui/ServiceUi.kt`、`ui/FeatureRow.kt`：颜色进 `service_theme.xml` 与 drawable，图标进 `ic_service_*.xml`，开关行改用公共 `GalaxySettingRow`。

`RemoteConnectionStatus.label` 改为 `labelResource(state): Int`，`failure` 分类链未改；文案资源 `service_remote_state_*`。

## 4. 诊断页

`DiagnosticActivity` 只 inflate + 生命周期/结果转交；`DiagnosticPageController` 承接按钮、观察者、扫描状态、分页 offset 与导入。

- 布局：`activity_diagnostic.xml`（返回/说明/结果/重新准备/日志/Shell/ROOT/ADB/扫描/分页/认证覆盖/L6/L7）；
- IO：日志读取与 `QnxCredentials.store` 在构造注入的执行器上运行，文件流 `use` 关闭，`destroy` 关闭自有 `ExecutorService`。**U1 实际用的是 `newSingleThreadExecutor`（无界 `LinkedBlockingQueue`），不是有界队列**；此项已在 R1 改为 `ThreadPoolExecutor(1,1,ArrayBlockingQueue(2),AbortPolicy)` 并补日志请求合并。
- 请求码 71 与 `*/*` 归 `ServicePageCommands`；成功导入仍沿既有 `prepare`；
- 扫描点击只请求一次，服务快照回填只改文案不发请求；offset 按实际 items 推进。

## 5. 兼容性与明确例外

- `GalaxyStyle.button` 的 `radius`/`surface` 参数保留签名；**U1 当时只加载固定 4dp 背景，真实 2dp 调用方（`GalaxyConfigurationTabs`）被静默忽略**，原“历史调用方只传 4dp”的说明不成立；此项已在 R1 改为按参数把半径作用到本实例内容 `GradientDrawable`。非默认 `surface` 时仅对次按钮内容层 tint，宿主色板仍生效（产品映射中 `product_ui_control == galaxy_ui_control`）。
- `GalaxyStyle.surface/rounded` 保留为宿主注入色板与自绘装饰的运行时例外；静态卡片/按钮/输入/选中态均改为资源。
- `GalaxySettingsCard` 的相邻行分隔线是登记的绘制例外（需读取行的 `textInset` 与真实布局位置）。
- 功能行图标改为公共行图标槽（32dp、文字色）；原先 46dp 强调色图块随 `FeatureRow` 删除而收敛，视觉统一到共用设置行，交互与命中区域不变。

## 6. 遗留（不在本批）

- 其余 `L7*` 页面（首页/设置/连接）与 `GalaxySettingsActivity` 仍未按页拆 XML，属 M1/M2；
- `GalaxySettingsActivity` 内已有的手写控件未见重复建设之前不动；
- 诊断页 `getParcelableArrayList` 仍走平台旧 API（按任务要求只迁既有读取，不新增流程）；
- 服务端输出所有权/HAB/QNX/车辆协议未触碰。

## 7. R1 修正（2026-11-12）

审计反例推翻了本记录的三处论断，均已按《U1-R1-确定任务书》修正，详见 `U1-R1-实现记录-20261112.md`：

1. **日夜刷新**：`GalaxySettingTextLayout`/`group`/弹窗曾只 inflate 静态颜色，未接回 `GalaxyStyle.bind`，原实例 refresh 不生效；R1 已接回同一 palette 机制。
2. **文字样式两轨**：XML `TextAppearance` 缺 `lineHeight`，代码仍用数值重建样式，导致同一 LABEL 行高 35px vs 28px；R1 改为角色样式 + dimens 单一来源，代码仅在 View 层补 `setLineHeight`。
3. **radius 与 IO**：见上文两条修正。
