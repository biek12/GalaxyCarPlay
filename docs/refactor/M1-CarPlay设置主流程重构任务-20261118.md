## 连接动作顺序

1. `connect` 先确认协议，停 reporting/codec probe，再进车型音频确认、首次无线前置、P2P 可用性或 MANUAL hotspot gate，检查 busy/配置错误/热点关闭/手机选择。保留 Android 33 首次通知权限记录与原选择续接。无活跃会话的前置不可因页面重建重复触发。
2. 通过后设 pending、刷新，既有会话先 `stop`，只有完成回到主线程、宿主仍有效且协议可用，才保存 transport 并打开原 `CarPlayHostActivity`。无会话直接走同一完成动作。重连沿当前 controller transport，关闭中或已 pending 拒绝重复，空/已关闭会话给原提示。
3. `stopFromHome` 已连接时确认，再禁用按钮并调用原 stop。等待连接时直接取消，完成回主线程刷新。页面入口有现有会话时可打开投屏，不隐式重连。自动连接仅保持 Activity 原首次启动判定，深链、资源回填、普通路由、旋转均不新增连接触发。
4. 保留现有 `L7HotspotTask`/`L7HotspotActions`、`L7WirelessHotspotGate`、USB worker 的生命周期及取消位置。无线/USB/配置页离开和销毁时用原 dispose/close；不要持有旧 View。测试通过注入具名平台/会话边界观察生产动作，避免新建通用接口层、第二套状态模型或反射私有字段。
