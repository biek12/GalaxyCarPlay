# U1 标准用例与交审门槛

本机 Robolectric sdk=30（已备缓存）及真实 Android Gradle 编译，不开模拟器、不连车辆。用例覆盖本批生产入口，不追求数量；同一动作的几个正常输入合并参数化。字符串扫描、资源文件存在、另写算法模型、只测State不进页面，均不能替代本表。

## 1. 门槛命令

在指定worktree：

```bash
GALAXY_REFACTOR_CACHE=/Users/anjon/Documents/GalaxyPlay/.work \
  bash scripts/verify_android_refactor.sh
```

脚本运行实际生产源码的Android编译、XML资源处理和以下测试，检查JUnit非空/零失败/零跳过。只排除三个未变native资产准备任务；不会关闭Kotlin/资源/测试，不打APK，不签名安装。完整日志、结果清单和源码摘要在worktree `.work/refactor-u1-validation/`，交付时复制到任务logs。首次环境基线可加`--baseline`，只跑现有用例；**最终交审不得使用该选项**。

## 3. 可测试入口的边界

- Presenter/Controller可通过默认参数注入生产AutoClient创建函数、时钟、系统/IO边界；默认仍调用真实实现。只允许为上述明确系统边界注入，不抽通用业务端口框架、不重写AutoClient、不stub Activity/生产控件。
- 验证点击后**真实配置/Intent/结果View**，不只assert回调字符串或State字段。协程/worker由可控队列推进，测试不靠sleep碰运气；销毁检查没有待执行ticker和旧View更新。
- DG-02合成导入只证明UI交接和生命周期；不冒充认证解析或QNX登录通过。资源/XML通过和宿主截图不冒充车机显示通过。
- 实现记录若列特殊自绘例外，必须指出实际类和资源外壳；不能扩出新的普通手绘控件。

## 4. 格式/资源/差异自查（工程检查，不计为业务测试）

1. 本批完整Kotlin/KTS使用固定ktlint及Lead配置format/check，第二次不变。
2. XML用固定xmllint格式化/解析；确认格式前后文本资源和format占位符语义不变。AAPT资源处理、binding生成必须实际通过，不以xmllint解析替代。
3. 查本批全部固定可见文本、尺寸、普通背景/图标的资源引用；不以简单正则数量宣布合格，检查实际调用。
4. 实际宿主页面可附日/夜/放大字体渲染PNG供Lead人工对照；标“宿主合成环境”，不能拿示意HTML冒充App截图。截图为辅助证据，不能替代测量/点击行为断言或真实车机验收。
5. diff无越界、无私有材料、无协议/默认值偷改；无手写整页View树/万能Constants/新重复实现；工作树干净，commit与最终测试源码摘要一致。
6. 对照Common组件复用映射检查单一实现；common旧入口和新XML入口使用同一测量/交互代码。必要L7委托变化由下游真实编译和原Cluster用例验证，不为“委托一行”堆字符串检查Test。

## 5. 最终回执模板

VALIDATION每项记录：ID、执行命令、起止时间、exit、测试suite/案例、实际观察、日志和报告路径、fixture/替身范围。未执行与失败如实写；必测有任一未通过即`BLOCKED_VALIDATION`。

`READY_FOR_REVIEW`必须同时有：最终commit、完整编译成功、全部必测通过且0跳过、语言格式通过、源码摘要/范围自查、实现记录和遗留。不允许“请Lead再编译一下”附在READY后面。
