## R1-F1 · includeFontPadding 回到 View 层

**问题**：R1 把按钮的 `includeFontPadding=false` 移进 TextAppearance，但 `setTextAppearance` 不应用该属性，`GalaxyUi.Button` 的 View style 又没声明，真实按钮与普通 Button 适配都回到 true。

**修复**：

- `GalaxyUi.Button`（View style）声明 `android:includeFontPadding=false`；XML 真实创建的 `GalaxyActionButton` 直接生效，`GalaxyUi.Button.Text` 继承同一声明。
- `GalaxyUi.TextAppearance.Button/ButtonCompact/TextButton` 中的无效同名声明删除，不用 TextAppearance 冒充 View 属性。
- `GalaxyStyle.button`（既有普通 Button 兼容入口）在应用 TextAppearance 后，用仅含 `AndroidR.attr.includeFontPadding` 的单元素数组（天然升序、try/finally recycle）从对应 View style 读取并设置到真实 view；normal 读 `GalaxyUi.Button`、compact 读 `GalaxyUi.Button.Compact`，两者同一 false 合同。
- 新增 View style `GalaxyUi.Button.Compact`：parent=`GalaxyUi.Button`，仅覆盖既有 compact 资源（`GalaxyUi.TextAppearance.ButtonCompact`、`galaxy_ui_button_min_height_compact`、`galaxy_ui_button_padding_horizontal_compact`、上下 0dp），不改任何视觉参数；宿主 decorate、主/次/禁用、动态 radius 与 refresh 行为均未动。

## R1-F2 · 文字按钮 26sp 行高进 View style

**问题**：`GalaxyUi.Button.Text` 未声明 `android:lineHeight`，原 `GalaxyTypography.apply(button,18,26,false)` 的行高合同在迁移后丢失（实测 26px → 35px）。

**修复**：

- `dimens.xml` 新增 `galaxy_ui_text_button_line_height=26sp`，`GalaxyUi.Button.Text` 的 **View style** 声明 `android:lineHeight` 引用它（不放进 TextAppearance——`setTextAppearance` 不应用段落行高）。
- 保留 18sp 字号、无字体附加留白（继承 `GalaxyUi.Button`）、64dp 最小高度（`galaxy_ui_touch_target`）、start=0/end=12dp、上下=8dp、`start|center_vertical`。
- `GalaxyViews.textButton` 的 bind 只重设文字色与背景；`galaxy_ui_button_text` drawable 无 padding（已核对源文件），背景重绑定不改已声明 padding，故无需恢复逻辑，由属性矩阵实测核对。

## R1-F3 · 设置行改平台四参默认样式构造

**问题**：R1 另写 `applyRowStyle` + 无序 `ROW_ATTRS` 手工解析，违反 `obtainStyledAttributes` 的 attrs 升序平台契约，且偏离“把默认 style 资源传给 LinearLayout 四参构造”的指定方案。

**修复**：

- `GalaxySettingRow` 主构造父类调用改为 `LinearLayout(context, attrs, defStyleAttr, R.style.GalaxyUi_SettingRow)`；三段式参数与代码构造重载保留。
- **删除** `applyRowStyle` 与 `ROW_ATTRS`，不换任何手工排序/下标解析器；orientation/gravity/padding/minHeight 的解析与优先级交回平台（API 21+ 可用，ui minSdk 24 无需改 SDK）。
- 自有 `galaxyTitle/Description/Value/Icon/AccessoryPosition` 仍由 AAPT 生成的 `R.styleable.GalaxySettingRow` 读取 + recycle；80/96dp 行高切换逻辑（`update`/`onMeasure`）与图标/操作槽/测量算法不动。

## 新增测试（只补约定场景，不删不弱化旧断言）

- `GalaxyXmlComponentsTest.buttonsAndTextButtonKeepContractedViewAttributes`：normal/compact `includeFontPadding=false`；textButton 18sp/26sp、无字体留白、64dp 最小高度、既定 padding 与 `start|center_vertical` 重力；enabled 切换与 `GalaxyStyle.refresh` 后属性不丢、不重建 View。
- `ServiceHomeBehaviorTest.settingRowsUsePlatformDefaultStyleForLayoutAttributes`：真实 `ServiceActivity` XML 行默认水平排布、20/16dp padding、说明行 96dp 最小高度；代码构造行同一默认来源；图标/开关与回填不受影响。
