## 3. 三项确定修法

### S1 按钮字体附加留白

1. `GalaxyUi.Button`的**View style**声明`android:includeFontPadding=false`，使XML真实创建的GalaxyActionButton生效；Text样式继承这一项。TextAppearance里的同名无效声明移除，不用它冒充View属性。
2. `GalaxyStyle.button`还服务于既有普通Button调用方，不能仅修XML后遗漏它。该兼容方法在应用TextAppearance后，从对应View style读取includeFontPadding并设置到真实view。读取单一属性可用仅含`AndroidR.attr.includeFontPadding`的单元素数组（先`import android.R as AndroidR`）（天然升序），必须recycle；normal/compact保持同一false合同。不建通用样式反射/复制框架，不改调用方类型，不重新手造整套控件。
3. 如需要compact View style，以现有GalaxyUi.Button为parent，仅覆盖已存在的compact字号/尺寸资源，不能改变原视觉参数。宿主decorate、主/次/禁用/动态radius和refresh行为保持。

### S2 文字按钮26sp行高

在dimens新增明确`galaxy_ui_text_button_line_height=26sp`，由**GalaxyUi.Button.Text的View style**设置`android:lineHeight`；保留18sp sans-serif、includeFontPadding=false、start|center_vertical、64dp最小高度、start=0/end=12dp、top/bottom=8dp。不得只放进TextAppearance，因为普通TextView.setTextAppearance不应用段落行高。

GalaxyViews.textButton继续inflate同一XML，运行时只绑定文案、事件和颜色/背景刷新。背景重绑定如果影响已声明padding，应在现有公共适配入口恢复从同一View style取到的padding，不写另一份固定数字；由正常属性矩阵实际核对，而不是凭推测加回退。

### S3 删除设置行手工属性解析，使用指定平台构造

`GalaxySettingRow`主构造的父类调用改为：

```kotlin
LinearLayout(context, attrs, defStyleAttr, R.style.GalaxyUi_SettingRow)
```

保留原三段式参数和代码构造重载。**删除applyRowStyle与ROW_ATTRS**，不换成手工排序/下标的另一套解析器；LinearLayout本身处理原生orientation/gravity/padding/minHeight及样式优先级。该四参构造从API21可用，当前ui minSdk24无需改SDK。

自有galaxyTitle/Description/Value/Icon/AccessoryPosition继续由AAPT生成的R.styleable读取、recycle；需要默认样式时将同一defStyleAttr/defStyleRes传入，不手拼无序资源ID数组。内容变化引起80/96dp行高切换仍留原状态逻辑，不偷改图标/操作槽/测量算法。
