### 行为保留要点

- `switchPage/loadLibrary/ensureEditor/setEditor/leaveDraft/openEditor/newTheme/saveTheme/applyTheme/startOutput/themeMenu/nameDialog/pickTheme/pickAsset/onActivityResult/attachAsset/fields/displaySettings/message/onConfigurationChanged/onBackPressed/onDestroy` 全部留原 owner，顺序与字符串未改；仅去掉全限定类名、加注释与格式化。
- observer 仍按 qnxReady → rootReady → `AutoCluster · ${status}` 三元顺序；`onState` 同前缀；初始 footer「正在连接 AutoService」；`message` 仍 Toast + footer。
- 缩略图唯一生产入口 `ThemeActions.thumbnail(target, metadata, active)`；`ImageView.tag` 的 Thumbnail 票据与 `closed/ticket.cancelled` 复用保护完全不动。Adapter 只把行绑定对象放 `row.root.tag`。
- 卡片状态顺序：同 id 异 revision「使用中 · 有未应用修改」→ 同代「正在使用」→ builtIn「内置模板 · 保存为副本」→ 否则「自定义主题」；使用按钮仅同 id 同 revision 为「已应用」，不新增禁用逻辑；edit→id、apply→metadata、more→完整 entry。
- 当前主题 preview 只在 active 非空时以 `active=true` 请求；active 为空时清空 View 与旧票据，避免上一代异步图片回填冒充当前。
- 不可读数量 Toast 用 `plurals`/占位符，只在 `update` 发出，`getView` 不重复弹出；「文件已保留」语义不变。
- 组件库仍是 `ComponentGallery` 的每行三个真实样式预览，只浏览不添加；本批只读，主题库固定两列，两者不混淆。
