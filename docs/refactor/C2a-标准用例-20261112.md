| 用例/类 | 真实入口及输入 | 可观察输出 |
| --- | --- | --- |
| T1 主题库两列及复用；ThemeLibraryPageTest | Activity中装入真实ThemeLibraryPage及XML，update含3个真实ThemeLibraryEntry元数据的ThemeLibrary；从adapter取两行并复用第一行 | 2张card/行，尾项INVISIBLE，实际比例图片宽高符合532/1920；当前主题header有独立预览；更新/复用后文字、缩略图请求id/revision/active标志、点击都对应当前项，不触输出命令 |
| T2 状态和点击；ThemeLibraryPageTest | 同id同revision、同id新revision、其他内置、其他自定义这四种正常数据；实际点击edit/use/more及header编辑/新建/导入 | 可见状态分别正在使用/有未应用修改/内置副本/自定义，已应用按钮只在同代出现；edit回id、apply回metadata、more回完整entry；各一次且无错项。header回当前active，不为空时才编辑；切换active为空后不会显示旧图片 |
| T3 日夜/不可读计数；ThemeLibraryPageTest | 两个资源Context分别day/night实际inflate页面；update带不可读id清单；measure/draw | 固定文字、背景、按钮引用公共日夜资源，可见且无裁切；提示真实数量与文件保留语义，列表getView不会重复Toast。保存日/夜宿主截图，不把资源值断言代替截图检查 |
| T4 真实外壳；ThemeShellBehaviorTest | 启动ThemeActivity；切组件库→我的主题、configurationChange重建壳再返回仪表；后台观察仅用Robolectric系统边界隔离 | 真实XML标题/tab/footer/内容slot，3tab等宽56dp、初始footer资源（启动后的observer允许更新为实际连接状态，不硬断言仍在连接）；tab顺序与原路由一致，组件库仍三列真实预览且无添加；配置后原page保留，新View可操作，返回finish；无新增显示/安装命令 |

缩略图后端允许以记录函数代替`actions::thumbnail`，仅用于确定列表绑定对象和回调；不mock页面/adapter。生产始终复用原ThemeActions的票据/缓存/线程，不另写假缩略图作为真实渲染结果。T4实际ThemeActions可本机运行，测试只观察本批外壳行为，不改旧IO/Store；要等待异步时用可复现完成信号/队列同步，不用任意sleep。

`Robolectric @Config(sdk=30)`与NATIVE绘制沿现有配置；系统服务不可绑定/启动由shadow隔离，不连车、不启模拟器。图片与列表元数据标为宿主用例数据。截图建议沿1000×1800保存到`cluster/build/outputs/refactor-ui/`，含日/夜主题库和组件库壳，人工核对标题、两列卡片、操作槽和文字未裁切。
