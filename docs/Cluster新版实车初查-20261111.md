离线源码修正：

1. AutoCluster重复启动相同元素方案不再重发图片；AutoService对已经接收的相同方案不增加 revision、不重做图片导入。客户端重连仍重放方案。
2. 静态图片资源证明不再混入每次变化的运行租约代次，避免同一图片因租约变更变成“新安装”。候选字节摘要与固定原件校验保留。
3. NFS回执读取错误独立记录；连续缺少回执满续租窗口后才进入运行核验，短暂缺口显示等待回执。已安装进程的健康核验再做连续观察，避免单次缺口触发交接。
4. 在固定本车ClusterFunction两个析构槽补充释放入口，覆盖未经过uninitialize而直接析构的退出；在Domain销毁前撤销自有节点与强引用。构建核对两个析构槽的原始地址，渲染／UI交接标志改用原子访问。

上述是离线代码整改，尚未装车。反复切换是否消失、异常是否消除、USB／手机卡顿原因及长时间运行仍未现场验收；不登记为已解决。
