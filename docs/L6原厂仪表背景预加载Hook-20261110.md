## 原厂入口与拦截范围

| 本地证据 | 候选实际行为 |
| --- | --- |
| `ReadOnlyDiskFile` 在 `0x60df68` 调 `open@plt`，`w1=0`。原厂随后将返回 FD 存入对象，在 `0x60deb0` 用该 FD 走原有 `mmap`。 | SO 拦截 `open`，要求返回地址等于本次原厂 `ReadOnlyDiskFile` 调用点的下一条指令 `0x60df6c`。只匹配此调用点、只读、精确的原厂 `background.kzb`。相对路径另核对当前工作目录。 |
| 原厂 ELF 动态符号表导出 `_ZTV15ClusterFunction`，已采集两份 HMI 的原厂回调槽和代码段一致。 | SO 读取动态导出的虚表锚点，用 `+0x60`、`+0x48` 槽里两个已知 RET 的地址核对当前映像和 ASLR 基址。虚表只读。 |
| `kzsEGLSwapBuffers` 在 `0x53ac60` 跳 `eglSwapBuffers@plt`。 | 原样调用真实 EGL，资源命中后第一次成功提交打一次标记。该标记不区分画面上的像素。 |

QNX ABI 使用本机目标镜像 libc 核对。其 `dlsym` 分支和诊断字符串对应 `RTLD_DEFAULT=-2`、`RTLD_NEXT=-3`，`_vopen` 在 `0x803a0` 检查 bit 8 决定是否读取创建权限。Hook 对其他资源和写打开原样转发。首版默认观察模式，只有显式设置 `GALAXY_G733_BACKGROUND_PROBE=replace` 时才尝试替换。候选来自固定私有路径，构建时锁定 SHA-256，运行时核对实际交给 Kanzi 的同一 FD 的完整字节校验和与长度，再将文件偏移复位。候选不可用时保留原厂读取，并单独记录拒绝。[Hook 源码](../tools/research/g733_background_hook.c) · [QNX dlsym 反汇编](../.local/research/g733-background-offline-20261110/libc-dlsym.txt)

## 证据分层

| 阶段 | 证据 | 判断 |
| --- | --- | --- |
| 装载 | 新 PID 的映射包含自有 SO，且同轮日志出现 `G733_HOOK_READY_OBSERVE` 或 `G733_HOOK_READY_REPLACE` | 动态链接和版本锚点在这个进程成立 |
| 命中原厂调用 | 观察模式出现 `G733_ORIGINAL_BACKGROUND_OPEN` | 原厂在已知 Kanzi 调用点打开了目标 KZB |
| 读取候选 | 替换模式出现 `G733_CANDIDATE_BACKGROUND_OPEN` | 该次原厂打开返回了已核对的候选 FD |
| 提交 | 出现 `G733_EGL_SWAP_AFTER_RESOURCE_OPEN` | 资源打开后有 EGL 成功提交，尚不能判断当前变体 |
| 可见结果 | 暗色 BG1 实屏出现测试图，原厂挡位及告警显示可核对 | 背景消费和共存结果，独立于手机、歌词、焦点和网络 |

音乐原型第一轮只有 SO 加载证据，没有出现组件回调。第二轮记录了挂接日志和两行裁剪画面，未达到交付效果。第三轮等不到新音乐数据，新排版未验收。背景验收从第一轮就用静态资源和固定视觉标记，避免把业务状态、进程加载和可见结果混在一起。[音乐原型实际记录](CarPlay原厂Kanzi音乐卡片原型-20261103.md#第二三轮结果与用户结束现场调试)

## 本轮产物与现场边界

已编译 QNX AArch64 双 LOAD 候选 `libgalaxy_g733_background_probe.so`，只依赖 `libc.so.4`，导出 `open`、`eglSwapBuffers`。SHA-256 为 `d4ac5d29afc28adf9648f82d0ff1682aec25c368d0bc92a27de088c5cbbdd5b0`。宿主替身在 ASan/UBSan 下通过精确调用点筛选、观察模式、候选 FD 复位、错样本和缺文件时保留原厂、变参创建权限直通、失败 EGL 不记成功与成功 EGL 只记一次。宿主测试直接执行 Hook 逻辑，没有模拟 QNX 动态链接器或 Kanzi 渲染。构建沿本项目重建 ABI，非正式 QNX SDP 产物。[构建脚本](../scripts/build_g733_background_hook.py) · [宿主替身](../tools/research/test_g733_background_hook.c) · [候选与证据](../.local/research/g733-background-offline-20261110/preload-verified/)
