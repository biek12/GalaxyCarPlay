## 5. 视觉与移动约束

- 中控只适配现有 L6／L7 共用竖屏。实际分辨率、密度从允许读取的既有配置／文档确定；未知就登记，不猜车型尺寸。
- 仪表画布 1920×532，预览保持此比例，不把仪表缩略图拉成长条装饰卡。
- 原厂音乐区先按现有约280px宽／140px高候选边界设计；标题、歌手、四行、短进度。当前歌词第二行，上1／下2；保留原厂封面与外层容器。不得直接把旧324px遮罩卡片塞进去。
- 四行原厂文字与完整自定义主题的文字设置可共享概念，但不同出口可支持的属性须有标注。
- 继承项目 FlymeAuto 日夜色阶、文字角色、设置分组卡、细圆角、蓝强调、触控尺度。绿色仅表示实际运行／连接等状态，未收到回执不能常绿。
- 图标优先复用现有项目资源。原厂安全状态不用近似素材冒充；未获素材明确列缺口。
- 组件库每行三个实际样式预览，只浏览；添加仅在编辑器。保留全部已有组件类型，不按历史“17类”标题删掉后续扩展。
- 字体／间距／图片参数给可读单位与范围，不让用户输入裸 JSON／ABI／Shell。技术信息集中诊断页。
- 长中文、超长曲目、文件名、未知值、系统字体放大均要有版式处理。
- “保存草稿”“应用到仪表”“恢复原厂”语义明确，避免一个大开关同时改模式、背景、Root和投屏。

## 6. 必画流程与状态

1. 老用户进入：保留旧主题／模式 → 修改草稿 → 取消或应用。
2. 选原厂增强 → 调整音乐 → 预览 → 应用 → 等真实回执。
3. 选图片 → 系统文件选择 → 完整保留／主动取景 → 日夜预览 → 取消或应用。
4. CarPlay／本机地图分别等待来源 → 首帧 → 运行；无源不暗换其他背景。
5. 只有当前句／完整四行／无歌词／暂停／切歌／seek／曲首曲尾。
6. 模式切换：旧模式撤销 → 新模式提交 → 实际回执；失败显示真实阶段。
7. 单项恢复音乐／背景与全部恢复；二者不互相误停。
8. 服务断开、Root由用户关闭、恢复未完成、重复点击、页面退出后台持续。

预览是演示，实际状态是接口输入。设计稿中两者分别标识；不从开关值推导“已显示”。
