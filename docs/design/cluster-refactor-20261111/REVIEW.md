# 修订边界

2026-11-11。首版混入 AutoService 连接帮助，并把仪表音乐卡片当作 App 常驻侧栏，用户否决，首版作废；此前截图 music-preview.png 不代表本版。

本目录只设计独立 AutoCluster App。入口为“仪表／主题／设置”，各页只处理本页任务。原厂增强和完整自定义分别进入各自配置，不把主题编辑器塞进原厂增强。仪表音乐卡片仅在“音乐卡片”页提供预览，参数属于其下方；其他页面不常驻播放器。背景页只选背景，应用后才显示运行状态。

AutoService Wi-Fi 改动独立，入口不出现在此原型。公共 UI 组件为另一份工程交付，组件目录不出现在 App 用户流程；原生 Wi-Fi 跳转已移出 auto-ui，归 AutoService 功能实现。

本轮为关键流程审阅，示意曲目、封面、背景和仪表预览均标注演示；不是已经运行的 Android App，也不是实车截图。原型保留“仪表／主题／设置”App导航；进入二级页后只显示返回和当前任务。待确认导航、原厂增强配置、音乐配置预览、背景选择、应用与恢复反馈后，再扩展全部编辑器细节与日夜稿。
